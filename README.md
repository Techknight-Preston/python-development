## Python Week 7 - File Handling and CSV Reports

### Assignment Files

- `my_notes.py`: Writes, appends, reads, and counts notes using file handling.
- `my_notes.txt`: Stores the four notes generated by my_notes.py.
- `hubs.csv`: Contains learner names, hub information, and scores.
- `report_builder.py`: Reads learner information from the CSV and generates a report.
- `report.txt`: Contains the generated learner report, including total learners, passes, failures, and average score.
- `README.md`: Describes the assignment files and explains the file append mode.

### Reflection

If I changed "a" to "w" in Question 1, the existing notes would be erased when the program writes the fourth note. This is because "w" overwrites a file, while "a" adds new content without deleting existing content.
